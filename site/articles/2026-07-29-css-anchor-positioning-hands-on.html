01 — anchor-name / position-anchor / anchor()

基本の3ステップ

① アンカー側に anchor-name: --名前 を付ける（値は必ず -- で始まる dashed-ident）。 ② 追従側を position: absolute か fixed にする。 ③ position-anchor で名前を指す。

これで「関連づけ」は完了ですが、まだくっついてはいません。 実際に繋ぐのは top / left などの inset プロパティに anchor() 関数を書いたときです。anchor(bottom) は 「アンカーの下端の位置」を長さとして返すので、calc() の中にも入れられます。

Livetop: anchor(bottom) / left: anchor(left)
anchor
アンカーの真下・左端揃え
/* ① アンカーになる要素 */
.anchor {
  anchor-name: --p1;
}

/* ②③ 追従する要素 */
.box {
  position: absolute;        /* absolute か fixed 必須 */
  position-anchor: --p1;
  top:  anchor(bottom);  /* 上端 ← アンカーの下端 */
  left: anchor(left);    /* 左端 ← アンカーの左端 */
  margin-top: 10px;        /* 隙間は margin か calc() で */
}

/* 論理プロパティ版（縦書き・RTL でも破綻しない） */
.box {
  inset-block-start:  anchor(end);
  inset-inline-start: anchor(self-end);
}
  • anchor() の第2引数はフォールバック値です。anchor(right, 20px) と書くと、 アンカーが存在しない／inset プロパティと軸が噛み合わない場合に 20px が使われます。
  • 軸が合わない指定（例：bottom: anchor(right)）は無効になり、フォールバック値に落ちます。 top/bottom には縦方向、left/right には横方向の <anchor-side> を。
  • アンカーが display: none だと関連づけ自体が切れ、 追従要素は「直近の位置指定された祖先」を基準に配置されます。
02 — position-area

position-area は 3×3 のマス目

anchor() を4辺ぶん書くのは正直しんどい。そこで position-area です。 アンカーの箱を中央マスとする 3×3 グリッドを想像して、どのマスに置くかを名前で指定します。

下のデモの点線が、その 3×3 グリッドそのものです（中央の枠がアンカー＝中央マス）。 マスをクリックすると位置指定要素がそこへ移動します。

Live · クリックで移動position-area: top
anchor
position-area
SPAN / 省略記法： 
.anchor { anchor-name: --pa; }

.box {
  position: absolute;
  position-anchor: --pa;
  position-area: bottom center;
}

値の読み方

  • 2値指定：行 × 列。top left、bottom center のようにマスを1つ選ぶ。
  • span-*：top span-left は「上の行に置き、中央マスと左マスにまたがる」。 span-all は3マス全部。
  • 1値だけのときの挙動が独特です。 top（物理値）は top span-all 相当、 start（論理値）は start start 相当、 center は center center 相当。
  • 物理値（top/left）と論理値（start/end）を混ぜると宣言ごと無効になります。 top span-inline-end はダメ。座標系（x-start/y-end）も同様に系統を揃えて。

サイズが勝手に決まる件

幅を明示しないと、position-area 配置の要素は width: max-content 的に振る舞い、 置かれたマスの範囲で折り返します。bottom center のように中央列に置くと、 幅がアンカーと同じになります（最小幅は min-content なので、いちばん長い単語ぶんは確保される）。 意図した幅にしたいなら明示するか、次の anchor-size() を使ってください。

03 — anchor-center

アンカーの中心に揃える

anchor() で細かく詰めつつ「でも横方向はアンカーの中央に揃えたい」。 これは inset だけだと calc(anchor(center) - 50%) のような芸当が必要ですが、 justify-self / align-self に anchor-center という値が用意されています。

Liveleft: anchor(left)
かなり長いアンカー要素
中央に揃えたい吹き出し
.box {
  position: absolute;
  position-anchor: --p3;
  top: calc(anchor(bottom) + 10px);
  justify-self: anchor-center;   /* 横方向をアンカー中心に */
  /* 縦を揃えたいときは align-self: anchor-center */
}

ツールチップの矢印を中央に出したいときの定番です。 position-area: bottom center でも中央には来ますが、あちらは幅がアンカーに引きずられます。 幅を自分で決めつつ中心を合わせたいなら anchor-center が正解。

04 — anchor-size()

アンカーの寸法に連動させる

anchor() が「位置」を返すのに対し、anchor-size() は「寸法」を返します。 width / height / min-* / max-* などのサイズ系プロパティに書けて、 inset や margin にも書けます。

下のスライダーでアンカーの幅を変えてみてください。追従側が比例して伸びます。

Liveanchor width: 120px
anchor
幅 = アンカー幅 × 1.6
高さ最小 = アンカー高さ
.box {
  position: absolute;
  position-anchor: --p4;
  position-area: right;
  margin-left: 12px;

  width: calc(anchor-size(width) * 1.6);
  min-height: anchor-size(height);
}

/* 論理値・別アンカー指定・フォールバックも可 */
.other {
  inline-size:  calc(anchor-size(self-inline) * 4);
  margin-left:  calc(anchor-size(width) / 4);
  inset-inline-end: anchor-size(--other-anchor height, 100px);
}

注意点がひとつ。left: anchor-size(width) のように inset に書いた場合、 それはアンカーの位置ではなく「包含ブロックの端からアンカーの幅ぶん」の意味になります。 追従はしません。位置を追わせたいのは anchor()、寸法だけ借りるのが anchor-size() と覚えてください。

05 — position-try-fallbacks / @position-try

はみ出しそうなら、勝手に反転する

Floating UI を捨てられる最大の理由がこれです。 既定位置で画面（正確には包含ブロックやスクロールポート）からはみ出すとき、 ブラウザが代替位置を順に試して、収まる最初のものを採用します。

手っ取り早いのが try-tactic キーワード。 flip-block（上下反転）、flip-inline（左右反転）、flip-start（対角に入れ替え）を並べるだけ。 下のデモを上下にスクロールすると、下端でツールチップが上に飛びます。

Live · スクロールしてねflip-block
anchor
下に出るけど、はみ出しそうなら上に回る
/* パターンA：キーワードだけで済ませる */
.tooltip {
  position: absolute;
  position-anchor: --p5;
  position-area: bottom span-all;
  margin-top: 12px;
  position-try-fallbacks: flip-block, flip-inline, flip-block flip-inline;
}

/* パターンB：候補位置を自分で定義する */
@position-try --shift-right {
  position-area: right span-bottom;
  margin: 0 0 0 12px;
  width: 200px;
}
.tooltip {
  position-try-fallbacks: --shift-right, flip-block, flip-inline;
  /* 収まる候補が複数あるとき、面積が最大のものを選ぶ： */
  position-try-order: most-height;
}
  • @position-try の中に書けるのは inset 系・margin 系・サイズ系・position-area・ align-self/justify-self など、位置とサイズに関わるものだけです。色などは書けません。
  • position-try は position-try-order と position-try-fallbacks の一括指定です。
  • どの候補が採用されているかは anchored container queries （@container ... ）で拾って、矢印の向きを変えるといった応用ができます。
06 — position-visibility

アンカーが見えなくなったら、隠す

スクロールでアンカーが画面外に出たのに、ツールチップだけ宙に浮いて残る——あの気持ち悪さの解決策です。 position-visibility: anchors-visible で、アンカーが見えている間だけ表示されます。

Live · アンカーを画面外へスクロールanchors-visible
anchor
アンカーが消えると
私も消えます
.box {
  position-visibility: anchors-visible;
}

/* 取りうる値 */
  always         … 常に表示（初期値）
  anchors-visible … アンカーが見えている間だけ表示
  no-overflow    … 自分がはみ出したら隠す

隠れかたは visibility: hidden 相当（強く隠されるので子孫で打ち消せません）。 レイアウト上の場所は保持されます。

07 — anchor-scope

同じ名前のアンカーが複数あるとき

カードコンポーネントを3枚並べて、それぞれに同じ CSS を当てる。 素直に書くと anchor-name: --card が3つになりますが、 マッチするのはソース順で最後のひとつだけ。3枚ぶんのツールチップが右端のカードに集合します。

anchor-scope を親（この例では各カード）に置くと、 その名前の可視範囲がサブツリー内に閉じます。下のボタンで切り替えてみてください。

  all             … サブツリー内の全 anchor-name を閉じる
  --a, --b        … 指定した名前だけ閉じる
08 — Popover API × Anchor Positioning

実戦：ドロップダウンとツールチップ

popover 属性が「開閉・Esc・外側クリックで閉じる・トップレイヤー描画」を担当し、 Anchor Positioning が「どこに出すか」を担当する。この2つで、 ドロップダウンが JavaScript ゼロで完成します。

popovertarget で紐づけた時点で暗黙のアンカー参照が張られますが、 エンジン差があるので実務では anchor-name / position-anchor を明示するのが安全です。

#menu[popover] {
  position: fixed;
  inset: auto;                  /* UA 既定の inset:0 を解除 */
  margin: 0;                     /* UA 既定の margin:auto を解除 */

  position-anchor: --menu;
  position-area: bottom span-right;
  margin-top: 8px;
  position-try-fallbacks: flip-block, flip-inline;
}

ハマりどころは UA スタイルシートの打ち消しです。 [popover] には既定で inset: 0; margin: auto; が当たっていて、 これを消さないと画面中央に居座ります。inset: auto; margin: 0; を先に書いてから位置を指定してください。

ひとつ実務上の留意点。Shadow DOM をまたぐアンカー参照（別のシャドウツリーのアンカーを指す）と、 その周辺での anchor-scope の挙動には、まだエンジン差が残っています。 Web Components ベースの設計で使うなら、ここは実機確認を挟んでください。

段階的に導入する書き方

/* 1. まず従来の絶対配置で「そこそこ正しい」位置に置く */
.tooltip {
  position: absolute;
  top: 100%;
  left: 0;
}

/* 2. 対応ブラウザだけ上書きする */
@supports (anchor-name: --x) {
  .trigger { anchor-name: --tip; }
  .tooltip {
    top: auto; left: auto;
    position-anchor: --tip;
    position-area: bottom;
    justify-self: anchor-center;
    position-try-fallbacks: flip-block;
  }
}

JS からの判定は CSS.supports('anchor-name: --x')。 どうしても旧環境を揃えたい場合は oddBird の polyfill がありますが、 ネイティブが使えるときはネイティブに任せる分岐を必ず入れてください。
